# Jvy Wallet v0.7.0 — a clearer, more visual wallet

**Prerelease · Android 9+ · signed release APK · build 232**

This release collects the changes since the previous remote v0.2.15 baseline,
including the locally tested 0.3–0.6 builds. It is not a Play Store launch or a
claim that physical-device acceptance is complete.

## Highlights

- **Home, your way:** reorder and hide dashboard cards, put Safe to spend first,
  and restore defaults. Compact date controls remain available with cards hidden.
- **One Home timeline:** historical income, expenses, trend, spending breakdown
  and recent activity share the same exact dates. Current balance and future
  forecasts remain separate. Budgeting cycles and rolling history are retained.
- **Visual summaries where they help:** contextual charts lead management lists;
  Reports → Explore provides deeper analysis. Shared shaded time-series styling
  preserves real gaps and signed values, with exact-value disclosures.
- **Account activity that adds up:** transfer-aware charts and day totals use
  each account's native sending/receiving amount. Internal transfers are not
  counted as newly earned money in wallet-wide cash flow.
- **More understandable planning:** clearer budgets, goals, loans, dated assets
  and debts, shared calendar/time pickers and financial explanations.
- **Security and privacy:** PIN/biometric options and recovery, explicit capture
  preferences, protected security surfaces and hidden-balance chart suppression.
- **Import help:** copyable AI-conversion schema/guide, local validation and
  explicit confirmation. Jvy does not send your wallet to an AI provider.
- **Rate freshness:** manual Refresh, provider date and last successful refresh,
  plus stale/offline states. The open-source Currency API supplies daily
  reference rates, not live bank execution prices; manual overrides are retained.
- **UI coherence:** restored summary-card colors, outlined account actions,
  adaptive large-text layouts, corrected contact details and offline legal pages.

## Updating safely

1. Export a complete native financial backup and keep a separate verified copy.
   CSV is not a complete backup. Exported backups are not automatically encrypted.
2. Matching owner-signed `com.ivy.wallet` installations can accept this higher
   version code. Physical in-place upgrade testing remains pending; reconcile
   account balances, transfers, goals, loans and wealth values after updating.
3. Old `com.ivy.wallet.debug` demo builds are separate installations. Restore a
   full native backup into the private app and compare records before relying on
   it. PIN/recovery credentials intentionally do not transfer in financial backups.
4. A differently signed app using `com.ivy.wallet` cannot be replaced by this APK.
   Do not uninstall or clear its data just to bypass that conflict; preserve and
   validate a backup first. Private signing does not guarantee removal of Play
   Protect prompts.

## Verification and remaining limits

The coherence pass passed **336 focused cases / 24 suites**. The final reflow
follow-up reran **86 cases**, compilation and lint against the unchanged baseline.
The official release build passed release safety lint, shrinking and packaging.
Signature/certificate continuity, package/version, alignment, checksum and
privacy manifest flags were checked on the actual APK.

Phone, fold, landscape/DeX, dark/AMOLED and enlarged-text candidate renders were
reviewed. They do not establish real-device interaction, TalkBack, keyboard,
biometric/recovery/capture, notification/widget or large-wallet performance
acceptance. No screenshot goldens were promoted. Legal-copy and cohort review
also remain open. Treat this as a prerelease, not certified stable software.

Report reproducible issues at
https://github.com/joravarsinghing/ivy-wallet/issues — include version, Android
version and steps, but no private financial records, backups, PINs or recovery
codes. The README is intentionally left for the maintainer to update.
