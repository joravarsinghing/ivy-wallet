## Moving from the older test-signed Jvy app

This is not an in-place update of `com.ivy.wallet.debug`. The release package has its own app data and can coexist with that legacy package.

1. Unlock the old app and export a backup; retain a separate copy.
2. Install this APK and open the new installation from the installer's **Open** button.
3. Restore the backup into the new app. Compare accounts, currencies, balances, goals and net worth before relying on it.
4. Configure PIN/fingerprint and generate new recovery credentials for this installation. Authentication secrets intentionally do not transfer through financial backups.
5. Keep the old app until the restored data and new recovery setup are confirmed. No automatic uninstall or data clearing is part of this release.

If another installed app already owns `com.ivy.wallet` with a different signing certificate, Android will reject replacement. Preserve its data and resolve that package conflict deliberately; do not uninstall or change the release identity automatically.
