# ADR 0010: Financial calculation explainability

- Status: Proposed; freeze at Gate 0
- Date: 2026-10-13

Deterministic financial calculations precede AI explanations. Every important number (safe-to-spend, budget status, emergency coverage, net worth, change decomposition) must expose input facts, date range, currency/FX assumptions, exclusions, and rounding. AI may explain approved calculation results but cannot be the source of financial truth.
